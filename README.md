# Bem-vindo! 👋 <a name="id01"></a>
Este repositório contém o código-fonte de uma réplica do site do Discord, desenvolvido para fins de estudo e prática de desenvolvimento web.

# 📝 Sobre o Projeto
Este projeto foi criado com o objetivo de replicar a interface e funcionalidades básicas do site do Discord, utilizando tecnologias modernas de desenvolvimento web como HTML5, CSS3 e JavaScript.
